# Resume PDFs

Drop your resume PDFs in this folder using these exact filenames so the
"Download Resume" menu in the top bar picks them up automatically:

- `resume-1page.pdf`   — 1-page summary CV
- `resume-academic.pdf` — Academic / long-form CV
- `resume-2page.pdf`   — 2-page professional CV

To change what appears in the menu, edit `RESUME_OPTIONS` in `src/App.tsx`.
